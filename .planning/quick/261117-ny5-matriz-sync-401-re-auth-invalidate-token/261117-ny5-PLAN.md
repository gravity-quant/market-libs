<objective>
Fix the sync matriz client's 401 re-auth-once flow so it actually re-authenticates.
Today `Client._request` (client.py ~L456-460) only sets `self._state.token = None` and
calls `self._ensure_token()`. `_ensure_token` falls through to `TokenStore.get_sync()`,
which still considers its cached token fresh (monotonic age <= 23h), so the retry
re-sends the SAME rejected token, gets a second 401 and raises `AuthenticationError`.
The async client (aio.py L500-507) is the correct reference.

Purpose: real-world triggers are server-side token revocation and host suspend
(time.monotonic does not advance during sleep, so a >24h token looks fresh).
Output: fixed `client.py` + sync regression test in `test_client.py`.
</objective>
