<objective>
Build the pure, IO-free MUT-MD-01 foundation: the three typed request models (`NewSymbol`, `NewSymbols`, `SymbolPatch`) that serialize OUT to wire JSON, and the three `_core.py` builders that turn a serialized dict into a `RequestSpec`. Both are pure functions with fully-defined I/O — ideal TDD targets — and neither touches the gate or the transport.

Purpose: These are the composable parts Plan 03's dispatch methods wire together. Building them independently (they touch only `models.py`/`_core.py`, not the shells) lets this plan run in Wave 1 in parallel with the gate (Plan 01).

Output: Three frozen request-model dataclasses with hand-written `to_dict()` and a client-side 1–500 `ValueError` guard; three pure builders setting `idempotent=True` (DM-03) and `authenticated=True`; unit tests for serialization, batch bounds, and builder specs.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| consumer payload → request model | Untrusted symbol batch size + field values cross into a typed model before any dispatch. |
| request model → wire dict | `to_dict()` fixes the exact JSON shape/keys sent to the primary-extractor. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-25-05 | Tampering | duplicate mutation via retried non-idempotent POST | accept | All three symbols builders set `idempotent=True` per DM-03/spec (retry-safe); the `idempotent=False` no-retry mechanism (`request.extensions["idempotent"]`) is exercised by Phase 26 (`POST /calendar/holidays`). Real server idempotency revalidated live in Phase 27 (A3); flips to False there if a retried POST duplicates state. |
| T-25-07 | Denial of Service / Input Validation | oversized/empty batch (`NewSymbols`) | mitigate | Client-side 1–500 `ValueError` in `NewSymbols.__post_init__` before any spec build or HTTP dispatch (V5). Testable: Task 1 bounds cases. |
| T-25-08 | Tampering | wrong wire key (`marketId` vs `market_id`) silently ignored by server | mitigate (partial) | `NewSymbol.to_dict()` emits snake_case `market_id` per source-plan schema; mocked wire-body test asserts the key. Real key confirmed live in Phase 27 (A2). |
| T-25-SC | Tampering | npm/pip/cargo installs | accept | No package installs (pure additive stdlib/dataclass code). |
