## Recommendation

**Recommended verdict:** GO with Phase 16 source-migration prerequisite.

**Rationale:**

1. Of the 3 FAIL items (1, 4, 6), ALL trace to the same root cause: `aio.py` is the source-of-truth
   but its current shape was authored independently of codegen (v1.1 Phase 7 wrote `aio.py` from `client.py`,
   not the other way around). The fix is a one-time, well-bounded source migration of ~30 LOC on `aio.py`
   (see 001a/FINDING.md ## Ámbito Rule Config Draft §Phase 16 source-migration setup steps).

2. **Critically:** zero hunks from the round-trip diff classify as Recipe-2 class 3 ("Semantic NOT
   fixable via additional_replacements"). Class 3 is the ONLY class that signals an unfixable unasync
   failure mode — its absence means the tool is structurally sound for this codebase.

3. All Wave 2-4 evidence (001b marker × `from __future__`, 001c matriz construct audit, 001d matriz
   deny-list intactness) PASS unconditionally:
   - Marker is grammar-neutral (PEP 263 / PEP 236 compliant).
   - Matriz `aio.py` 852 LOC enumerates 109 async-only constructs with **zero unresolved rows**;
     the audit's classifier resolves every row deterministically (D-SCOPE-02 merge gate satisfied
     automatically, no operator triage needed).
   - The 4 deny-listed matriz files (`_token_store.py`, `_refresh_policy.py`, `_refresh.py`,
     `ws_client.py`) are sha256-byte-identical pre/post a simulated codegen run while `aio.py`
     itself is sha256-transformed — confirming the `fpath_list` scope mechanism is sufficient.

4. Timebox is WITHIN-CAP and matriz audit is zero-unresolved — both the auto-NO-GO triggers from
   D-SCOPE-03 + D-SCOPE-02 are NOT activated.

5. The strict D-RIGOR-01 NO-GO reading (3 of 8 FAIL) is honored as the operator's gate. If the
   operator signs NO-GO on strict reading, that is legitimate and triggers Tasks 12-03-04a/b
   (D-NOGO-01 defers REFAC-06 to v1.3 libcst spike). The recommendation here is advisory only —
   the spike's job is to surface data, not pre-judge the operator.

**What "GO with Phase 16 source-migration prerequisite" means in practice:**

- Phase 16 starts with a 1-task prerequisite plan (or first task within Plan 16-01): apply the ~30 LOC
  ámbito source migration on `aio.py` (move `_validate_max_retries` definition, pin import order,
  pin `_REQUEST_TIMEOUT` placement, extend sync surface with `close()` delegator, normalize docstring
  shape, align inline comments per 001a/FINDING.md ## Ámbito Rule Config Draft).
- After that source-migration commit, re-run the 8-item evidence checklist; expected: 8/8 PASS.
- Then proceed to per-package codegen serial rollout (ámbito → iol → higyrus → matriz).

## Phase 16 Production Integration Recommendation (GO branch)

### Marker syntax (per 001b)

```python
# @generated by unasync from aio.py — DO NOT EDIT BY HAND.
# To modify, edit aio.py and run `make codegen` (Phase 16 setup).

"""<module docstring>"""

from __future__ import annotations
```

Marker is grammar-neutral (PEP 263 / PEP 236); ast.parse + ruff format + mypy strict all accept it.

### Pre-commit hook (Phase 16 install)

```bash
# Regex matching @generated marker:
head -1 packages/<pkg>/src/<pkg>/client.py | grep -q '^# @generated by unasync'
```

When the marker is present AND aio.py is newer than client.py by mtime → reject the commit
(codegen drift). Phase 16 installs this hook in `.pre-commit-config.yaml`.

### `make codegen` Makefile target

```makefile
codegen:
	uv run --with unasync python scripts/codegen.py
	uv run ruff format packages/*/src/*/client.py

codegen-check:
	uv run --with unasync python scripts/codegen.py
	git diff --exit-code packages/*/src/*/client.py
	# fails CI if the in-repo client.py differs from a fresh codegen run
```

### CI `lint-codegen` job sketch

```yaml
lint-codegen:
  runs-on: ubuntu-latest
  steps:
    - uses: actions/checkout@v4
    - uses: astral-sh/setup-uv@v3
    - run: uv sync --all-packages --all-extras --dev --frozen
    - run: make codegen-check  # fails if generated drifts from committed
```
