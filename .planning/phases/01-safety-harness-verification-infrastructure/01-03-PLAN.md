<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| driver stdout → terminal/log | Driver output (tokens, response dicts) must be redacted before printing (HARN-03) |
| env → driver run | Missing creds must SKIP cleanly per driver, never partial-run (HARN-01) |
| driver → Matriz mutation path | The mutation path must be unreachable from the driver unless double-gated (HARN-02) |
| child driver stdout → aggregate runner output | The runner must not re-emit raw child stdout that could contain a credential |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-13 | Information Disclosure | driver credential prints | mitigate | Every token/cred print routed through `redact()`; output dicts through `safe_print(text, secrets)`; main_iol.py's `token[:12]` raw slice replaced by `redact(token)` (HARN-03) |
| T-01-14 | Information Disclosure | main_verify.py child-stdout aggregation | mitigate | Runner prints per-package RAN/SKIPPED status only, never re-emits raw child stdout verbatim (avoids leaking a token a child printed) |
| T-01-15 | Tampering | Matriz mutation path in main_matriz.py | mitigate | Any mutation branch guarded by `mutating_allowed()`; default prints `SKIPPED (mutating, guard off)` (HARN-02/D-16); order placement never run live regardless (REQUIREMENTS Out of Scope) |
| T-01-16 | Reliability / fail-safe | driver env gate + runner continuation | mitigate | Each driver `sys.exit(0)` on missing creds after the verbatim SKIPPED line; runner captures and continues, never halting (HARN-01/D-14/D-15, Pitfall 6) |
| T-01-SC | Tampering | npm/pip/cargo installs | accept | No package installs (stdlib `subprocess`/`sys` + the already-built `verification/` module; RESEARCH Package Legitimacy Audit = none) |
</threat_model>
