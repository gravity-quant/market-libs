## Assumptions (flagged — unverified)

- **Interruption / parallelism safety is asserted by construction, not verified — and this plan is
  where it actually bites.** Task 2's test mutates a tracked source file
  (`market_data_client/_core.py`) and restores it in `finally`. Under a normal interpreter this is
  safe, and under CI it is additionally safe because each matrix leg runs one package sequentially
  with no shared mutable state across legs. But a `SIGKILL` between the write and the `finally`
  would leave the tree dirty, and a future move to parallel test execution would let another test
  observe the mutated file. Neither case has been exercised. The failure mode is loud and
  recovered with a single `git checkout`, which is why OQ-3 chose this over a ~30-line tmp-tree
  copy — but it is an accepted risk, not an eliminated one. Recorded here rather than discovered
  later.
- **The exact wording of import-linter's broken-contract output line** was not observed during
  planning (doing so would have required mutating a tracked file outside a GSD execution). Task 2
  instructs the executor to encode what a real run produces rather than a remembered string.
