### `tools/check_surface_types.py` (CI gate, AST batch)

**Analog:** itself — `_strip_optional:600-634`, `_field_annotation_is_untyped_mapping:636-706`,
`_adjudicate_field:862-896`, `scan_surface_types:899+`.

**Existing predicate shape to mirror** (`:691-706`) — note the quoted-annotation
re-parse and the `return True` on `SyntaxError`; the new predicate must reproduce
both:

```python
    inner = _strip_optional(annotation)
    if isinstance(inner, ast.Constant) and isinstance(inner.value, str):
        try:
            inner = _strip_optional(ast.parse(inner.value, mode="eval").body)
        except SyntaxError:
            return True  # an uninspectable annotation is not a spared one
    if _is_any(inner):
        return True
    if isinstance(inner, ast.Name | ast.Attribute) and _base_name(inner) in _MAPPING_BASES:
        return True  # bare `dict` says less than `dict[str, Any]`
    if not isinstance(inner, ast.Subscript):
        return False
```

**Do not change `_strip_optional`'s contract** — the mapping predicate depends on the
unconditional strip. Add a sibling returning the "was there a wrapper" signal
(RESEARCH's `_optional_inner`, comparing `ast.dump` before/after).

**Adjudication seam to extend** (`:890-896`) — OR the two predicates and emit a
*distinct* message so a mapping violation and a link violation stay
distinguishable:

```python
    if not _field_annotation_is_untyped_mapping(node.annotation):
        return None, None
    reason = _is_field_exempt(qualified)
    if reason is not None:
        return reason, None
    detail = f"is annotated `{ast.unparse(node.annotation)}`"
    return None, f"    `{package}.{qualified}` {detail} on the exported surface"
```

**Threading the classifier** — `scan_surface_types` already holds `import_root` in the
per-package loop (`:932`); compute the `ClassDef`-name set once there and pass it into
`_adjudicate_field` alongside `package_dir.name`. The existing field loop
(`:992`) is the only call site:

```python
            for qualified_name, _member_name, field_node in field_candidates:
                reason, violation = _adjudicate_field(qualified_name, field_node, package_dir.name)
```

**Docstring conventions this file enforces on any new function** (visible throughout
`_field_annotation_is_untyped_mapping`): numbered shape list, a "Phase N code review,
CR-xx" provenance paragraph for every widening, and an explicit *"spared on purpose"*
paragraph naming what stays green and why. A new predicate without those three reads
as foreign in this file. Per RESEARCH F-6, the docstring must also state: (a) the
full-tree walk is a **classifier, never a candidate source**; (b) `dict[str, Model] | None`
is deliberately **not** covered; (c) exception classes are `ClassDef`s too and would
redden.

**Hard constraint:** stdlib `ast` only. No `import <pkg>`, no `eval`/`exec`, no

## Shared Patterns

### Docstring provenance rewrite (applies to 4 sites)

**Source of the rule:** Phase 36 CR-02, cited by D-05.
**Apply to:** `test_models.py:202`, `test_models.py:437`, `test_null_object.py:113-118`,
`models.py:182-186` + `:267-269`.

When the branch that produces a test's observed behaviour changes, the docstring citing
the old branch is rewritten **in the same commit**. Leaving it is a false-provenance
claim about a branch that no longer executes — the same defect class the rule was
written to prevent.

### Ratchet discipline (applies to every gate edit)

**Source:** `tools/check_surface_types.py:673-681`, restated in matriz's RED fixture.

```
Ratchet discipline says a red gate is never resolved by weakening the gate; the
corollary D-01b adds is that an out-of-scope red is resolved by NARROWING the
predicate, never by exempting the foreign field and never by editing the foreign
package.
```

Concretely: if the widened predicate reddens matriz, **narrow the discriminator** — do
not add a `_FIELD_EXEMPTIONS` entry and do not edit `packages/matriz-client/**`.

### Every module opens with `from __future__ import annotations`

Present in every file this phase touches. It is *why* the gate reasons over `ast`
strings and why the runtime re-evaluates with `get_type_hints`.

### Derived artifacts are regenerated, never hand-edited

**Source:** `verification/regen_snapshots.py` (docstring, D-11).

```bash
uv run python verification/regen_snapshots.py
```

Commit the diff in the **same commit** as the source change. Acceptance criterion:
exactly 2 changed lines in `verification/snapshots/iol-client-surface.txt`
(`:11`, `:21`), and within them exactly the `puntas` annotation —
`'list[Punta] | None'` → `'list[Punta]'` and `'Punta | None'` → `'Punta'`.

### Duplicated test helpers are copied, not extracted

`_write_fake_package` exists in both RED fixtures on purpose; matriz's docstring
(`:21`) records that factoring it out *"would be this repo's first"* shared test helper.
Same rule as DT-03 (no shared code between packages).
