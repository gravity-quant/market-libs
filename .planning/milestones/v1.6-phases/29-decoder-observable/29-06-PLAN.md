<objective>
Fan out to `matriz-client`, the package whose decode semantics genuinely differ
from the other two, and prove the difference survives as a declared policy rather
than being harmonized away.

matriz reverses the coercion helper's argument order, returns `None` for a
missing scalar instead of a typed zero, returns the `empty()` constructor for a
non-dict payload instead of building defaults from an empty dict, carries no
slots, and passes scalars through unvalidated. Its `UnknownFrame` is not a
`SafeModel` at all. Each of those is a row in the semantics matrix and a field of
the policy constant.

Purpose: this is where the "never harmonized in silence" requirement is actually
tested. A mechanical rewrite that made matriz behave like higyrus would pass a
naive test suite and silently change published behaviour for every matriz
consumer.
Output: `_decode.py` with matriz's policy, `MatrizDecodeError`, a delegating
`models.py` that preserves all seven documented differences, the mode carrier,
the filter fix behind the package-specific pre-scan block, and the divergence
suite.

Decisions implemented: D-02 (verbatim copy into five packages), D-03 (flag on
`_ClientState`, ContextVar bound at both `_request` methods with no reset), D-05
(filter fix plus caplog sentinel, with the package-specific pre-scan ordering
invariant preserved), D-07 (matriz keeps its own semantics as a declared policy,
never harmonized), D-09 (the nine RESPONSE `Literal` aliases decode as strings
and out-of-set values are reported, never enforced).
</objective>
