## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| published package contract → consumers | v0.3.0 and v0.3.1 are tagged and installed; a narrowed type or changed return type breaks consumers silently at type-check time |
| builder `idempotent` flag → retry transport | The flag alone decides whether a failed mutation is re-sent; a wrong value duplicates state under `5xx` precisely when nobody is watching |
| findings markdown → cycle-closure validator | A promoted status without a resolvable regression link produces a false PASS |
| second armed run → develop | The confirming re-run is a second real write cycle with the same residue obligations as the first |
