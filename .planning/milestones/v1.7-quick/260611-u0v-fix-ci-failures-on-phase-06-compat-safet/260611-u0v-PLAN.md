<objective>
Fix two CI failures on branch `phase-06-compat-safety-net`:

1. The public-surface snapshot generator (`verification/test_public_surface.py::_enumerate_surface`) emits body lines like `"IOLClientError : class : "` (trailing space) when the introspected `signature` is empty. Pre-commit's `trailing-whitespace` hook strips that space from the committed files, but the test then re-enumerates and the in-memory string still carries the trailing space — snapshot test fails AND the hook keeps modifying the files. Same root cause is fed by `regen_snapshots.py` via `_enumerate_surface`.

2. `uv run mypy --strict packages/iol-client/tests` fails because the test files reach into `iol_client._get_default()` (a deliberately private name re-exported in `iol_client/__init__.py` but excluded from `__all__`) and `from iol_client.aio import _raise_for_response` (which `aio.py` re-imports from `client.py` per Plan 04 B8 — but mypy strict's `implicit_reexport = False` rejects underscored re-exports). Solution: qualify the call sites with the canonical module path — `iol_client.client._get_default()`, `iol_client.aio._get_default()`, and `from iol_client.client import _raise_for_response`.

Purpose: unblock CI on this phase branch with two atomic commits (one per bug) the user can review and push manually.

Output:
- Task 1 commit: fix snapshot generator + regenerated 4 snapshots (no source/test changes).
- Task 2 commit: fix iol-client test imports/calls (no production code changes).
