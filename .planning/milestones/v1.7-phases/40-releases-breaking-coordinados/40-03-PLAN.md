<objective>
Behind a second, independent human gate, create one annotated tag per bumped package on the
live-re-resolved merge commit, push them by name, watch every `release.yml` run to success, verify
every public Release carries its wheel and sdist, and then prove the release is actually consumable
by installing each published wheel from its public URL into a throwaway Python 3.12 interpreter and
exercising a deep chain against the installed distribution.

Purpose: the tag push is the most irreversible operation of the milestone. A GitHub Release cannot
be cleanly un-published or re-pointed, and a mislabelled tag is a permanent public artifact. The
post-publish install is what turns "the pipeline reported success" into "a consumer can actually use
this" — ROADMAP criterion 3 and D-11 make that an in-phase task rather than a UAT afterthought.

Output: N public GitHub Releases, each with a verified wheel and sdist, each proven installable and
functional from its public URL.

This plan is `autonomous: false`. It carries the SECOND of exactly two blocking human checkpoints on
irreversible operations (D-07b), independent of the merge approval already given in plan 40-02.
</objective>
