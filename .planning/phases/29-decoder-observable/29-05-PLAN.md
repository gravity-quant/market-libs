## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| upstream JSON → walker | Untrusted market-data payloads carrying symbol and account identifiers cross into model construction. |
| walker → `logging.getLogger("market_data_client")` | New emission surface in a published wheel. |
| async task context → sibling task context | Two coroutines on one loop share a thread; a wrong carrier would leak one task's mode into another. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-29-22 | Information Disclosure | divergence record on market-data payloads | mitigate | Six all-str type-not-value keys; `record_shape` asserts no emitted value appears in a sentinel-built payload; in-package caplog sentinel on all three record surfaces. |
| T-29-23 | Information Disclosure | `MarketDataDecodeError` message | mitigate | Constructed from field path plus type names only; the strict tests assert the message carries no wire value. |
| T-29-24 | Spoofing | wire-supplied `received_at` overriding the client stamp | mitigate | The keyword injection bypasses the walker for that field; `snapshot_received_at_not_walked` asserts the keyword wins against a conflicting payload value. |
| T-29-25 | Tampering | one async task's mode leaking into a sibling | mitigate | ContextVar carrier plus the interleaved-async non-clobbering test and the parent-context-unchanged assertion. |
| T-29-26 | Tampering | zero-argument super breaking the slots-rebuilt override | mitigate | Acceptance criterion greps for the explicit two-argument form; the exercise test would fail at runtime otherwise. |
| T-29-27 | Denial of Service | duplicate divergences across a large catalogue read | mitigate | Index-free dedupe path plus a request-scoped collector opened at the top of `_request`. |
