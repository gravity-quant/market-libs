| mutation method → network | Whether a token fetch + POST/PATCH is emitted is decided by `_ensure_mutation_allowed()` at method entry. |

| T-25-02 | Spoofing/Tampering | mutation dispatched to unexpected/prod host | mitigate | Gate's exact-host leg runs before dispatch; host-mismatch dispatch test asserts 0 requests. |
