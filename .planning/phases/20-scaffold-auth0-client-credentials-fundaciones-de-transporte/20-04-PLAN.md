<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → Auth0 token URL | Absolute host; credentials POSTed form-encoded |
| client → market-data API | base_url; Bearer injected only when `spec.authenticated` |
| health path | anonymous — no token ever attached |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-20-02 | Information Disclosure | token sent to health/anonymous or wrong host | mitigate | `_send_auth_request` targets the absolute `auth0_token_url`; `_request` injects Bearer only when `spec.authenticated` (health passes False) |
| T-20-03 | Spoofing | stale token reuse | mitigate | `_ensure_token` gates on `_core.token_is_fresh`; `configure()` resets `token=None`+`token_expires_at=0.0` on credential rotation |
| T-20-08 | Denial of Service | 401 re-auth loop | mitigate | exactly-one re-auth then re-raise (no recursion); token endpoint 401 raises before the retry loop (mutation-gate) |
| T-20-06 | Information Disclosure | Bearer/secret in logs | mitigate | relies on `_logging.attach()` (Plan 03) wired at import in Plan 06; transport emits redacted WARN/ERROR |
</threat_model>
