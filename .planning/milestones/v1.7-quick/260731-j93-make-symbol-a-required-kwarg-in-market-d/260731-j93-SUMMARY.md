# Quick Task 260731-j93: Make symbol a Required kwarg in market-data-client Summary

Made `symbol` a required keyword-only `str` across the entire market-data-client `GET /marketdata/latest` surface (sync method + sync shim + async method + async shim + `build_latest_request` builder), fixed the four live-verification probes to pass a symbol, and added sync/async/builder regression tests — closing confirmed live findings F-01 (latest_sync) and F-13 (latest_async), where the client defaulted `symbol=None`, `drop_none` stripped it, and the develop API returned HTTP 422 `{"detail":[{"type":"missing","loc":["query","symbol"],"msg":"Field required"}]}` on every call.

## What Was Built

- **Task 1 — Production surface (d062761):** Changed `symbol: str | None = None` → required `symbol: str` at all 5 sites; kept `market_id`/`entries` optional. Updated the `build_latest_request` docstring to note `symbol` is now required. Sync and async mirrored verbatim. `get_latest_batch` / `build_latest_batch_request` (POST body) left untouched.
- **Task 2 — Probes (36aa94b):** `probe_latest_sync` and `probe_latest_async` now call `get_latest(symbol=_SAMPLE_SYMBOLS[0])` and `build_latest_request(..., symbol=_SAMPLE_SYMBOLS[0])`; batch probes unchanged.
- **Task 3 — Regression tests (68092d7):** `test_get_latest_requires_symbol`, `test_async_get_latest_requires_symbol`, `test_build_latest_request_requires_symbol` — each asserts `TypeError` at call time when `symbol` is omitted.
