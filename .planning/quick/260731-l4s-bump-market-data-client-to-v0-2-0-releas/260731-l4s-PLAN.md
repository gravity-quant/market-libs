# Quick Task 260731-l4s — Bump market-data-client to v0.2.0

## Context

Post-`v0.1.0` live verification (LIVE-MD-01) fixed 3 real client-vs-service bugs that
**broke the public API** (`get_latest.symbol` now required; `MarketDataSnapshot` /
`CalendarConfig` field renames; envelope-unwrap). Those fixes are on `main` but the
published release is still `v0.1.0` (buggy), and `pyproject`/`__version__` still say
`0.1.0` — a version-identity collision. This bumps to **v0.2.0** (semver minor, breaking
changes in a 0.x line) so a new tag/release can publish the fixed code.
