## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| event loop coroutine -> blocking `_token_cache` syscall | `asyncio.to_thread` boundary: blocking fcntl + JSON I/O runs in executor thread; await suspends coroutine; cancellation does NOT abort the thread (documented per D-A1) |
