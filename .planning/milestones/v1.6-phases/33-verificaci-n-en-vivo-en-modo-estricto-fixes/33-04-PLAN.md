<objective>
Bring `main_market_data.py` — the largest probe surface (43) and the largest declared floor (≥50) —
onto the Plan 01 mechanism, and give it the `_ENDPOINT_TEMPLATES` shape D-03 says it is missing.

Purpose: this driver has 55 broad-Exception handlers, every one routing through a single helper
`_finding_for_exc`, which today maps a decode divergence to `ERROR-MAP` with the title
`f"{name}: {type(exc).__name__} inesperado"` — unique per probe, so `idempotent_by_title` cannot
collapse it and a strict run mints one spurious `ERROR-MAP` finding per affected probe. Because all
43 call sites funnel through that one helper, the classification fix is a single edit rather than 55.
Separately, this is the only driver with a destructive surface, so the two-pass runner's safety
property (P-11) has to be made explicit here.

Output: the D-03 endpoint-template dict, a `SHAPE` branch inside `_finding_for_exc`, `probe_context`
on all 43 probes with `endpoint_scope` on the multi-endpoint health pair, and the two-pass strict flag
threaded through the single ctor sites without disturbing the mutation double gate.
</objective>
