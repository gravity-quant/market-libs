## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| local git → `refs/tags` on `origin` | Pushing a tag matching `*-client-v*` fires `release.yml` immediately; there is no ordering guard, no approval step and no dry-run inside the workflow. |
| tag → public GitHub Release | `release.yml` builds a wheel + sdist from the TAGGED tree in a clean runner and publishes them publicly. Once the Release exists the tag cannot be cleanly re-pointed. |
| agent → irreversible publish | Nothing in GitHub gates this operation; the human checkpoint is the entire access control. |
| release memory → future agents/consumers | This file is the instruction source for installing the package; a stale install line silently propagates a superseded version. |
