Build the load-bearing mutating-gate FIRST (GATE-MD-01), before any mutation surface exists. Output: A pure, adversarially-tested gate that raises on refusal with zero IO, uses exact-hostname matching, propagates to `with_options` views via shared `_ClientState`, and cannot be silently reset by a `configure()` call that omits the flag.
