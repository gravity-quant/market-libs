      ```
      def __init__(
          self,
          *,
          max_retries: int = 3,
          base_backoff_s: float = 1.0,
          max_backoff_s: float = 30.0,
          jitter: float = 0.25,
          fail_cache_s: float = 30.0,

      ) -> None
      ```
      Note: `sleep_fn` injection is REQUIRED for tests (validated pattern in spike `test_policy.py`).
    - Internal state: `self._lock = threading.Lock()`, `self._cached_failure_at: float | None = None`, `self._cached_failure_exc: BaseException | None = None`
    - Method `_compute_backoff(self, attempt: int, retry_after: float | None) -> float`:
      - If `retry_after is not None`: return `min(retry_after, self.max_backoff_s)` (no jitter for explicit Retry-After per spike convention)
      - Else: `base = min(self.base_backoff_s * (2 ** attempt), self.max_backoff_s); return base * (1 + random.uniform(-self.jitter, self.jitter))`
    - Method `_read_fail_cache(self) -> BaseException | None`:
      - Under `self._lock`: if `cached_failure_at is None` return None; if `time.monotonic() - cached_failure_at >= fail_cache_s` clear cache and return None; else return `self._cached_failure_exc`
    - Method `_store_fail_cache(self, exc: BaseException) -> None`: under `self._lock`, set `cached_failure_exc = exc; cached_failure_at = time.monotonic()`
    - Method `wrap(self, refresh_fn: Callable[[int], str]) -> Callable[[int], str]` returning a closure `wrapped(call_id: int) -> str` that:
      1. Checks `cached = self._read_fail_cache(); if cached is not None: raise cached`
      2. Loops `for attempt in range(self.max_retries + 1)`:
         - try `return refresh_fn(call_id)`
         - except `PermanentRefreshError`: `raise` (NO retry, NO fail-cache)
         - except `RateLimitedRefreshError as exc`: `last_exc = exc`; if `attempt < max_retries`: `self._sleep_fn(self._compute_backoff(attempt, exc.retry_after_seconds)); continue` else `break`
         - except `TransientRefreshError as exc`: `last_exc = exc`; if `attempt < max_retries`: `self._sleep_fn(self._compute_backoff(attempt, None)); continue` else `break`
      3. After loop: `assert last_exc is not None; self._store_fail_cache(last_exc); raise last_exc`
    - `__all__ = ["RefreshPolicy"]`
