## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Auth0 response → parser | Untrusted JSON crosses into `parse_token_response`; type-guarded before use |
| HTTP status → exception | `raise_for_response` classifies untrusted server status |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-20-03 | Spoofing | stale token reuse | mitigate | `token_is_fresh` requires `time.time() < token_expires_at`; `parse_token_response` bakes in the 60s `_TOKEN_TTL_BUFFER_SECONDS` so expiry is conservative |
| T-20-02 | Tampering | token grant path | mitigate | `build_token_request` sets `authenticated=False` and `path=""` so the grant never carries a stale Bearer and dispatches (Wave 3) to the absolute Auth0 URL, not `base_url` |
| T-20-05 | Information Disclosure | malformed/absent access_token | mitigate | non-str/empty `access_token` raises `MarketDataAuthError` rather than caching a bogus/empty token |
</threat_model>
