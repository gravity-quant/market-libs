<decisions>
## Implementation Decisions

### Spike experiment scope (discutida con operator)

- **D-SCOPE-01: Package coverage = ámbito round-trip + matriz construct audit.** Mínimo del ROADMAP success criteria. Ámbito es canary (no auth, smallest surface, pattern recurrente Phase 2 / Phase 6 / Phase 7). Matriz se audita en papel pero NO se round-trippea full — la enumeración de constructs (D-SCOPE-02) cubre el worst-case. iol + higyrus quedan **inferidos** de ámbito (mismo patrón de transport shell + `_core.py` builders); si Phase 16 descubre edge cases en iol OAuth refresh-token flow o higyrus event_hooks lock-protected mutation, se reabre el spike o se aplica fix inline. Riesgo aceptado: descubrimiento tardío en Phase 16, mitigado por el patrón v1.1 in-cycle bug-fix.

- **D-SCOPE-02: Matriz audit = enumeration + manual proof.** Para cada async-only construct enumerado en matriz `aio.py`, dos vías de clasificación:
  - **(a)** Vive en deny-list (`_token_store.py`, `_refresh_policy.py`, `ws_client.py`) → confirma que la deny-list config de unasync lo excluye (configurable via `Rule(fromdir, todir, exclude=[...])` o equivalente).
  - **(b)** No vive en deny-list → el spike redacta el sync equivalent esperado en un comentario inline en el spike notes y verifica que unasync con `additional_replacements` configurados lo emite verbatim (o byte-identical modulo ruff format).
  Cero constructs marcados "TBD" o "Phase 16 lo resuelve". Anti-Pitfall 6 (async semantics bleed into sync).

- **D-SCOPE-03: Time-budget cap = 1 día.** Si después de ~1 día dedicado de spike work ámbito round-trip + matriz audit no convergen a un GO claro (B8 identity preservado, ruff/mypy/import-linter green, byte-identical modulo ruff format), se dispara **NO-GO automático**. Patrón v1.1 Phase 10 spikes 001a/b/c (convergieron en ~1 día con 3-4 experimentos cada uno). Anti-rabbit-hole. Si el spike toma >1 día sin convergencia, el approach mismo es la señal: unasync no es el fit correcto a este scale.

### GO decision rigor (Claude's discretion — operator aceptó por default)

- **D-RIGOR-01: Beyond byte-identical (SC#1), el spike report MUST presentar TODOS los siguientes como evidencia GO** antes de que el operator firme:
  1. **Byte-identical round-trip ámbito** (`client.py` generated == `client.py` v1.1 hand-written, modulo `ruff format`).
  2. **B8 identity** preservada en `client.py` generated: `client._raise_for_response is aio._raise_for_response is _core.raise_for_response` (SC#2 explícito; anti-Pitfall 4).
  3. **`uv run ruff format --check`** clean sobre `client.py` generated.
  4. **`uv run ruff check`** clean (todas las rules E/W/F/I/B/UP/SIM/RUF/ASYNC/PIE/PT/RET/TID — incluyendo ASYNC1xx false-positives en `_sync/` files via `tool.ruff.per-file-ignores` si aplica).
  5. **`uv run mypy --strict`** clean sobre el paquete con el generated `client.py` en su lugar.
  6. **`uv run --package ambito-financiero-client pytest -q`** suite completa green sobre el generated.
  7. **`uv run lint-imports`** confirma que los 4 import-linter contracts existentes (`_core` cannot import `client`/`aio`) NO se rompen — el generated `client.py` sigue respetando la dirección.
  8. **`@generated by unasync from aio.py — DO NOT EDIT`** marker syntax probada compatible con `from __future__ import annotations` (mandatory todos los modules del repo per `CLAUDE.md`). El marker viene ANTES del `from __future__ import` per PEP 263 / ruff acceptance.

  Cualquier falla en 1-8 dispara NO-GO. Esto matches v1.1 Phase 10 rigor (los spikes TokenStore tenían stress tests runtime, no solo "compiles ok").

### NO-GO contingency (Claude's discretion — operator aceptó por default)

- **D-NOGO-01: Si unasync NO-GO en ámbito → cerrar spike + defer libcst a v1.3.** NO extender Phase 12 para evaluar libcst inline. Razones:
  1. El time-budget de 1 día (D-SCOPE-03) se rompería si evaluamos 2 tools serialmente.
  2. libcst evaluation requiere AST-level reasoning (no es token-replacement como unasync) — necesita su propio spike dedicado.
  3. v1.2 milestone scope ya está apretado (5 phases activos + 1 conditional). Agregar libcst spike inline es scope creep al milestone.
  4. El defer documentado a v1.3 mantiene la opción abierta sin bloquear el resto de v1.2.

- **D-NOGO-02: NO-GO close-out artifact** incluye:
  1. `.planning/spikes/SPIKE-005-codegen-tool-choice/NO-GO.md` con root cause analysis: qué falló exactamente (B8 break, ruff false-positives, marker syntax conflict, matriz construct sin sync rewrite, etc.).
  2. Update inline a `.planning/REQUIREMENTS.md`: tachar REFAC-06 del listado v1.2 y moverlo a "Future Requirements (Defer to v1.3+)".
  3. Update inline a `.planning/ROADMAP.md`: marcar Phase 16 como DROPPED + actualizar Progress table; nota de defer a v1.3.
  4. Add new pending todo `.planning/todos/pending/spike-codegen-libcst-v1.3.md` capturando el scope de libcst exploration (AST-level codegen, parser→tree→rewrite→codegen, etc.).
  5. Phase 17 (LIVE-03) queda desbloqueada — el operator puede correr `/gsd-plan-phase 17` inmediatamente después de Phases 14 + 15.

- **import-linter v2.11 contracts** existentes (4 forbidden) — runtime check de que codegen NO los rompe. Add: 8 nuevos contracts en Phase 16 (si GO) — el spike documenta el shape pero NO los aplica.

### Established Patterns

- **Spike-before-plan flag** (Phase 10 reference): research flag activo en ROADMAP → spike dedicado → wrap-up → Skill → auto-load durante implementación. Locked.
- **Per-package serial within phase** (v1.0/v1.1 lesson): ámbito → iol → higyrus → matriz. El spike usa ámbito (canary) + matriz (worst-case) como representativos; Phase 16 replica al resto si GO.
- **Throwaway code en `.planning/spikes/<spike-id>/<experiment>/`** (Phase 10 reference): el spike NO toca `packages/` directly. Round-trip experiments viven en sub-directories con código + finding markdown.
- **Byte-identical comparison modulo ruff format** (industry standard para codegen): compute `client.py` actual y `client.py` generado-luego-ruff-format, comparar con `diff`. Diff vacío = pass. Phase 12 SC#1.
- **`@generated by <tool> from <source> — DO NOT EDIT`** marker (psycopg / urllib3 convention): viene en línea 1 del file generado, ANTES del `from __future__ import annotations`. El spike confirma la compatibilidad ruff/mypy.
