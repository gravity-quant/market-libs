<objective>
TRACER SLICE, part 1. Build the canonical per-field walker as a new
`_decode.py` module in higyrus — the package whose `SafeModel` / `_coerce` pair
is the source every other copy descends from — and rewire higyrus's `models.py`
to delegate to it without changing a single return value.

This is the production-quality end-to-end decode path for one package. The four
other copies in Wave 4 are transcriptions of the body produced here; nothing
fans out until this slice is verified.

Purpose: today `_coerce` detects a type mismatch and throws the fact away
(`return value if isinstance(value, str) else ""`). The walker returns the same
default and additionally reports what it saw. Extra wire keys are not
detectable inside `_coerce` at all — both `from_api` implementations iterate
`dataclasses.fields(cls)` and call `data.get(name)`, so the payload's own key
set is never enumerated. That capability lives in the new `walk_model` wrapper.
Output: `_decode.py`, `HigyrusDecodeError`, a delegating `models.py`, and a
behaviour suite covering five divergence classes × two modes.

Decisions implemented: D-01 (the per-field walker is the primary engine and is an
evolution of the existing coercion helper, not a replacement), D-06 (record
vocabulary from the schema reducer), D-07 (per-package policy constant, no silent
harmonization; `from_api` preserved as the 872-test zero-edit merge gate), D-09
(the walker never enforces `Literal` membership).
</objective>

Public surface of the module:

- `DecodePolicy` — `@dataclass(frozen=True, slots=True)` with the seven fields
  named in `29-SEMANTICS-MATRIX.md` section 2: `missing_str`, `missing_int`,

- `STRICT_DECODE: ContextVar[bool]` named `higyrus_client_strict_decode`, default

- `DECODE_SCOPE: ContextVar[DecodeScope | None]` named
  `higyrus_client_decode_scope`, default `None`.
- `DecodeScope` — the aggregation collector. Holds a `set` of
  `(model, field_path, kind)` triples. Calling it with
  `(model, path, kind, declared, observed)` returns immediately if the triple was
  already seen in this scope; otherwise records the triple, then either raises
  the strict error or emits the record.
- `open_request_scope()` — binds a fresh `DecodeScope` into `DECODE_SCOPE` with
  `.set()` and no reset, mirroring the mode bind. Called from `_request`.
- `current_sink()` — returns the bound scope, or a new per-call scope when none
  is bound.
- `SILENT_SINK` — a module-level sink that records nothing, emits nothing and
  never raises. It exists for constructors that build an all-defaults instance
  without decoding wire data: matriz's `empty()` classmethod walks every field
  with a `None` value by design, and routing that through an emitting sink would
  produce one spurious `missing` record per field on every nested-model default
  and on every non-dict payload. Any package copy whose `models.py` has such a
  constructor uses this sink; higyrus has none today, so the constant is
  unreferenced here but must be present so the five copies stay byte-identical.
- `hints_for(cls)` — `functools.lru_cache`-wrapped `typing.get_type_hints`. This
  is the single highest-leverage change in the phase: with
  `from __future__ import annotations` mandatory repo-wide, every annotation is a
  string re-evaluated on each uncached call, which measures at roughly 89% of
  today's total decode cost.
- `walk_field(value, hint, *, path, model, policy, sink) -> Any`
- `walk_model(cls, payload, *, path="", policy, sink=None) -> dict[str, Any]`

`walk_field` preserves `_coerce`'s branch order exactly — Union/`T | None`, then
`list`, then nested model (duck-typed), then `str`, then `bool`, then `int` with the
guard that excludes `bool` (because `bool` subclasses `int` and an unguarded
branch collapses a boolean payload into a numeric field), then `float`, then the
bare pass-through. Insert one new branch for `Literal` hints BEFORE the bare
pass-through: it never checks membership, and it reports a `type` divergence only
when the value's runtime type does not match the runtime type of the literal's
members. The return values of every existing branch are unchanged; the only
addition per branch is a sink call immediately before returning a default, and
the `path` keyword threaded through the recursive calls. For a `list` element the
appended path segment is `[]` with no index, so identical divergences across
elements collapse under the dedupe triple.

`walk_model` is the new capability. When the payload is not a dict it calls the
sink once with kind `non_dict` and then builds all-defaults WITHOUT emitting the
per-field `missing` records (non-dict is terminal for reporting, lock 8). When
it is a dict it enumerates `sorted(set(payload) - {f.name for f in fields(...)})`
and reports each as `extra`, then walks every declared field in
`dataclasses.fields()` declaration order. Extra keys are reported before declared
fields; recursion is depth-first. That ordering is the determinism guarantee.
Use `fields(cast(Any, cls))` — the existing mypy-strict discipline in this file
for `get_type_hints`-driven code. Do not introduce a type-ignore comment.

The emitter builds the six contract keys and calls `_LOGGER.warning` for
`missing`/`type`/`non_dict` and `_LOGGER.info` for `extra`, with the constant
message from the aggregation contract. Wrap the logging call so any exception
raised inside logging or inside a consumer handler is swallowed — the decode
return path must be unaffected. Acquire the logger with
`logging.getLogger("higyrus_client")`, the same name `attach()` already equips
with `NullHandler` and `RedactingFilter`, so the new emission path inherits the
filter for free; do not call `attach()` and do not add a handler.

Add `HigyrusDecodeError(HigyrusClientError)` to `exceptions.py`, constructed from
